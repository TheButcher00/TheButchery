# TheButchery
The Butchery è un macello abbandonato trasformato in tempio dell’oscurità. Piastrelle bianche sporche di rosso sangue, pareti nere corrose e luci rosse pulsanti creano una vibe horror claustrofobica e carnale. Qui registriamo dj set hardtechno e techno oscuri, brutali e ipnotici, Carne, sudore, bassi che squartano. Benvenuti nel mattatoio sonoro.
